# 教练 5 问

试点排期前逐题记录原话摘要和待验证项，不把回答自动写成已验证需求。

1. **选手与换人**：首批有哪些选手代号？是否接受每位选手一套预绑定的独立 Bridge FC + RX？换一套桥可接受多久？
2. **谁操作 Session**：由谁在什么时候点开始/结束？一条 Session 对应一包电、一次起飞还是整段训练？
3. **DVR 工作流**：使用 DJI/Walksnail/HDZero/模拟或其他什么 DVR？当前每周 5 小时主要在找炸机前操作、过门线路、油门控制还是别的问题？
4. **老板要看的 3 个数字**：哪 3 个训练指标值得每周贴墙？每个数字会改变什么训练决定？
5. **现场与授权**：工作站、浏览器、屏幕距离、网络、采集卡、计时器和未成年比例是什么？谁负责取得并保管书面同意？

每题记录：回答、证据、假设、需要真机/法务/业务确认的人和截止时间。
