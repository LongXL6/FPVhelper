# FPVHelper 4 周试点运行手册

本手册是操作模板，不证明报价、收款、同意、硬件安装、云端资源、域名或生产发布已经完成。任何试点起算都以双方书面确认和真机验收记录为准。

## 角色

| 角色 | 责任 | 人员 |
| --- | --- | --- |
| 俱乐部负责人 | 确认范围、授权联系人、数据规则与试点起算 | 待填 |
| 主教练 | 维护代号、训练台账、DVR 基线和每周复盘 | 待填 |
| 工作站操作员 | 开关 Session、换桥、导出 JSON、记录异常 | 待填 |
| FPVHelper 支持 | 安装指导、版本记录、周报汇总、问题闭环 | 待填 |

## 起算前门禁

- [ ] 报价范围、硬件排除项、数据附件、支持渠道、税务/发票和退款规则已由双方书面确认。
- [ ] 若使用未成年选手数据，监护人书面同意已由有权主体收齐；未同意代号不得进入数据集。
- [ ] 每位参训选手已有独立、预绑定的地面 Bridge FC + ELRS RX 套件和台账编号。
- [ ] 客户只使用 `race.fpvsuperapp.com`；`helper.longxl.com` 仅内部完整验证且不计生产数据。
- [ ] 独立 FPVHelper Supabase、Vercel 路径和假名化统计已完成工程验收；若任一项未完成或书面确认未取得，统计保持关闭。
- [ ] 如启用统计，已按 [`analytics-provisioning-runbook.md`](analytics-provisioning-runbook.md) 完成 workstation ID 复制、token hash 登记、一次性安装、同域请求/独立数据库验证和撤销演练。
- [ ] 工作站按 [`workstation-install-checklist.md`](workstation-install-checklist.md) 检查。
- [ ] 已完成一条真实 UVC + 独立地面桥 + 本地 JSON 的真机验收记录。

任何复选框未完成都应记录为“未满足”，不得用演示数据、内部域或口头同意代替。

## 时间线

### T-14 至 T-11：范围确认

1. 发出报价/数据附件草案，收集书面修改。
2. 使用 [`coach-interview.md`](coach-interview.md) 完成教练 5 问。
3. 冻结试点代号规则、DVR 类型、Session 粒度和支持渠道。

### T-10 至 T-3：DVR 基线周

1. 不使用 FPVHelper 改变训练流程，只记录原有 DVR 复盘开始/结束时间。
2. 每次记录选手代号、训练包数、需要定位的问题类型和复盘分钟数。
3. 基线不足一周或记录不完整时，不宣称“复盘时间下降”。

### T-7 至 T-3：装机与同意

1. 为工作站建立受控浏览器 Profile 和本地导出目录。
2. 为每位选手登记独立地面桥套件；Binding phrase 不进入文档、日志或仓库。
3. 收齐书面同意并建立线下代号映射；同意编号只进台账，不进 JSON。
4. 在内部入口完成完整验证，结果标记为非生产。
5. 仅在独立 analytics Supabase、生产接收路径、书面确认和工程验收全部完成后登记客户工作站；否则保持统计关闭。

### T-0：真机验收与起算

1. 按 [`templates/hardware-acceptance-record.md`](templates/hardware-acceptance-record.md) 完成真实 UVC、Web Serial、3 分钟 Session、导出、重新解析和异常恢复。
2. 生产入口和 `/version.json` 指向同一已核验版本。
3. 俱乐部负责人和支持方书面确认起算日；此前不写“试点已启动”。

### 第 1–4 周

- 每周至少安排 2 次训练尝试；实际次数以台账为准，不预填成功。
- 每次按“选手代号 → 更换专属地面桥 → 验证 live → 开始 Session → 结束 → 导出 → 一句复盘”执行。
- 人工 Marker 只定位 DVR 时刻，不作为圈数或圈速。
- 每周汇总尝试数、有效 Session 数、导出数、故障、DVR 复盘分钟和未解决项。

## 每次训练 SOP

1. 确认飞行器拆桨完成地面检查，桥接飞控不接 ESC/电机。
2. 按 [`ground-rx-handoff-sop.md`](ground-rx-handoff-sop.md) 接入当前选手专属地面桥。
3. 核对页面是客户规范域、正确版本、真实画面、`connection=live`、正确选手代号。
4. 开始记录；台账立即记一次“训练尝试”，即使随后失败也保留在分母。
5. 训练中若串口、画面或电源异常，停止并记录错误码；不要把演示数据续接为真实记录。
6. 结束后导出 JSON，重新解析，填写复盘结论和 DVR 分钟。
7. JSON、代号映射和监护人同意编号分开保管。

## 停止与升级条件

- 桥接飞控出现写入、连接 ESC/电机或未知 MSP 命令：立即停止。
- 地面接收机干扰机上链路、需要现场重绑、出现 failsafe 或频谱疑问：停止飞行并回到拆桨台架。
- 统计在未书面确认时发出、出现原始错误/视频/RC 上传或第三方 SDK：关闭统计并升级安全问题。
- 同一验收项两轮复测仍失败：按双方书面条款处理，不自行宣布通过或退款。

## 周报证据

周报必须同时引用训练台账、可解析的本地 JSON、版本号和问题记录。没有生产事件、硬件或业务证据时明确写“未验证”，不得用内部 `helper.longxl.com` 记录补生产分母。
