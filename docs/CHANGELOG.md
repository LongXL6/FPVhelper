# FPVHelper 变更记录

本文件记录进入版本控制的产品变更；它不证明 CI、部署、生产或真机验收已经完成。

## [0.7.0-beta.3] - 2026-09-07

### 改进

- 共享视频输入支持选择 1–4 名选手，画面和选手位置只显示所选人数；每路输入独立记住数量。
- 减少人数时保留隐藏选手的姓名和裁切设置，当前选手若被隐藏则切回首位；人数不改变原 HDMI 画面的裁切比例。
- 录制及 ARM 监听期间锁定人数；录像沿用当前选手的独立取景与打杆 OSD。旧四人配置保持兼容。
- 新增“仅视频 DVR（无需飞控）”：不要求选手姓名、串口、遥控链路或训练数据库健康，直接保存当前完整或裁切画面，不烧录打杆叠层、不生成遥测 JSON。
- DVR 可使用已授权目录，也可选择仅本页记住的目录；训练数据库不可用时仍可直接写视频。准备、录制、收尾期间锁定模式与取景，取消启动、关页提醒和文件关闭确认独立处理。

## [0.7.0-beta.2] - 2026-09-06

### 修复

- 停止记录后独立冻结和保存遥控数据；视频仍在收尾时，可以查看与导出已保存的 RC 记录，媒体收据到达后再合并关联。
- 自动 JSON 导出绑定本次记录停止时的文件夹，手动导出使用当前文件夹；备注、媒体、终止状态和导出确认按 Session 合并，保护后续记录的状态。
- 兼容 ARM 自动记录的启动取消、连续 DISARM 和视频延迟关闭；旧记录的导出完成后只收尾其自身录像，不会误停新记录。
- 保留 100 Hz RC 采集目标和 20 Hz 历史节奏，复用 250 ms 样本计数刷新；油门曲线按主机接收时间展示并标记间断。

### 兼容与验证边界

- Session schema 2 保持兼容，浏览器本地数据库升级至版本 3；加载新版前结束旧页面中的采集，回滚版本也须支持 DB3，不删除或降级已有数据库。
- 本地回归使用合成设备、真实浏览器文件与存储接口；不代表真机、物理同步或长时间持续写盘已验收。默认关闭的本地测量工具不上传数据，整体性能收益仍待验证。

## [0.7.0-beta.1] - 2026-09-06

### 新增

- 在飞行工作台内提供默认关闭的 ARM 自动记录 Beta，共用当前选手、完整或裁切画面、摇杆 OSD、训练记录和保存目录。
- 按显式配置的地面桥 AUX 通道检测 ARM 请求；连续 DISARM 15 秒后自动保存，期间重新 ARM 继续同一段。原有结束按钮可手动结束并停用自动监听。
- 数据失联会取消结束倒计时并继续录像，最终记录保留数据缺口标记；启用期间锁定选手、输入、裁切和录制设置。

### 修复与验证边界

- 启动取消及并发停止等待本次视频与文件收尾；缺失视频收据不再确认为完整录像。旧 `/arm-record` 入口跳转主工作台。
- ARM 触发反映遥控请求，不是机上实际解锁确认。本地与模拟设备测试不代替比赛现场地面桥、接收机、采集卡和持续写盘验收。

## [0.6.1] - 2026-09-05

### 修复与诊断

- 实时识别自动启用 WebGPU FP16，初始化失败时回退 WASM q8；记录实际后端、固定权重哈希与回退原因。
- 解除固定 2 FPS 限制，支持 15/30 FPS 分析上限；只处理新帧且只有一个推理任务，显示实际完成速率。跟踪超时与目标帧率分开，修复超时后丢掉当前有效匹配。
- 显示实际裁切取景、匹配框与阈值前余弦分数、各阶段耗时和未形成候选的原因；完整指标随本轮 JSON 保存，可单独导出最近 120 次分析的本地诊断。
- 诊断不上传画面或元数据。以 5 秒检查点和最多约 4 Hz 的界面更新减少高速分析的额外开销，兼容旧版记录。
- Esc 不再把已连接飞控退回演示；取消尚未完成的连接、页面大屏、弹层和输入框各自处理退出。

### 验证边界

- 30 FPS 是分析上限，不保证实际机器达到；单张参考匹配仍需至少 3 次观察与接近、离场条件，模型候选继续人工复核。
- 视频＋打杆 OSD＋数据录制、100 Hz RC 目标和 20 Hz 历史节奏沿用；真实 FPV 穿越准确率、计时精度和多路持续性能仍需实测。

## [0.6.0] - 2026-09-05

### 新增

- 在打杆实时监看中接入单起终点门的实验计时面板，共用本机门档案，可从当前选手的裁切取景截图或导入照片配置目标门。
- 复用当前视频采集流，独立 Worker 执行固定模型，每秒最多分析 2 个新画面；模型候选保持待确认，支持人工确认、排除、改时刻和补记。
- 显示本圈参考计时、已复核圈数、最快与上一圈，提供独立本地历史库和唯一文件名的 JSON/CSV 导出。
- 每轮固定视频来源、选手、裁切、门版本和真实训练记录 ID；保存主机观察时间与可用的视频回调元数据，不伪造原录像文件身份或同步精度。
- 视频源/选手/取景/训练记录变化、后台或长时间无新帧时结束本轮，保留分析缺口；停止识别释放自身 Worker，不关闭共享采集流。

### 验证边界

- 实时模型结果仍需人工复核，不代表已验收的自动穿门或正式计时。2 fps 是取样上限，不是物理计时精度。
- 原有 100 Hz RC 采集目标、20 Hz 历史节奏和视频＋打杆 OSD 录制流程沿用。计时档案独立保存；本版本未把计时数字烧入视频，也未校准视频与打杆同步。
- 同时录像时先开始训练记录，再开始过门计时，才能固定关联该训练记录。每次分析一路取景，尚未验证四路持续推理。

## [0.5.0] - 2026-09-05

### 新增

- 独立的本地视觉实验台：用户导入自己的门照片或从录像选门，支持完整画面和四格选手画面、门档案保存与导入导出。
- 固定版本 DINOv2-small 真实特征匹配，独立 Worker/WASM 运行，最多 3 分钟离线取样，生成待人工复核候选。
- 候选确认、排除、改时刻和补记，追加修正历史并重算已复核起终点间隔；未处理缺口与待复核事件使相关区间不完整。
- 独立本地库、完整录像 SHA-256 匹配、取消与中断恢复、JSON/CSV 唯一文件名导出。

### 修复

- 多标签页保存视觉记录时，在事务内拒绝旧进度、原始候选或复核历史覆盖较新结果；冲突页面可导出修改并重新载入。
- 编辑选手名字时保留当前输入草稿，防止延迟返回的 Betaflight 自动名称改变光标位置并与手输内容拼接；未修改时离开输入框仍恢复自动名称。

### 验证边界

- 当前是离线录像实验，不是已验收的实时自动计圈；参考相似度与人工确认不能作为模型的过门准确率。
- 时间来自浏览器视频 seek 位置，未验证逐帧 PTS、物理过门精度、完整赛道或四路持续计时；不改变既有遥控采集和视频 OSD 录制链路。

## [0.4.1] - 2026-09-05

### 修复

- 授权目录中的重复 JSON 导出改为自动增加 `-v2`、`-v3` 等版本后缀，保留旧快照；同一 Session 的 ID 与视频关联不变。
- 已配置保存目录时，训练记录中的“导出 JSON”使用同一目录和版本保护；保存提示显示实际文件名，失败时不确认导出。
- 串行处理应用内同时发起的目录导出，名称探测遇到权限或读盘错误时停止，不将异常误当作文件不存在。

## [0.4.0] - 2026-09-05

### 新增

- 每位选手连接后自动读取 Betaflight Pilot Name，空名回退 Aircraft/Craft Name，旧固件使用只读 MSP_NAME；一次性名称探测不改变 100 Hz RC / 20 Hz 历史刷新。
- 保留既有手动名字，可直接改名或恢复自动；按选手隔离，断开重连重新读取，录制期间固定姓名用于画面、视频与原始数据。
- 浏览器支持时优先原生录制 MP4，不支持时在开始前明确显示 WebM；视频带打杆 OSD，JSON 单独保存原始数据，文件扩展名与真实容器匹配。
- 每个视频画面新增可见的“裁切与绑定”入口，直接定位对应选手，方便四合一输入分配画面。

## [0.3.1] - 2026-09-05

### 修复

- 视频＋打杆 OSD＋原始数据成为默认录制模式；开始按钮旁可直接切换录制内容，明确选择过“仅数据”的偏好继续保留。
- 主界面显示当前选手视频、真实遥控输入和保存目录的准备状态，提供打开输入、连接选手和授权目录的直接入口。
- 未满足全部开始条件时显示“待准备”，避免将已开启录像选项误认为已就绪；录制期间锁定模式。
- 延续当前选手画面烧录 OSD、WebM 关闭后确认收据和原始 JSON 同目录保存的流程，四人同时录制仍不在本版本范围内。

## [0.3.0] - 2026-09-05

### 新增

- 重构训练工作台、记录库与工作站设置，接回多路 UVC、选手画面裁切与独立遥控输入。
- 视频直接烧录左右摇杆及 −1000 / 0 / +1000 刻度，同时在授权目录保存原始遥控 JSON；结束时等待 WebM 写入关闭，再关联成功收据。
- IndexedDB 分块增量写入、已采集/已保存进度、历史摘要与按需读取详情。
- 采集质量与时钟/通道上下文，包括实际间隔分位数、缺口与可用时段；旧记录保持兼容。
- 本地训练备注、人工标记与 DVR 清单、合并周报、安装检查和主动本地诊断。

### 修复

- 摇杆缩小时坐标区保持正方形，各轴使用统一行程单位。
- 切换页面时采集与录像持续运行；改善收尾重试、异常输入和存储损坏的处理。视频文件关闭与记录完成前持续保留离页提醒。
- 旧库升级空间不足时保留历史记录只读访问与导出，暂停新录制；空间恢复后可重试迁移，不自动删除旧数据。
- 历史曲线在采集缺口处断开，孤立样本显示为点；详情读取失败可重试。
- 保持 100 Hz RC 采集目标与 20 Hz 历史节奏，避免重复样本和跨选手状态污染。

### 验证边界

- 录像叠层使用最新主机样本，尚未校准视频与遥控的时间偏移；主机采集缺口不等于 RF 丢包。
- 本地与模拟设备测试不替代真实桥接飞控、UVC、磁盘持续写入或业务验收。生产统计仍需满足既有明确授权和受限摄入配置，不随界面发布自动启用。

## [0.2.0] - 2026-08-31

### 新增

- CI workflow：锁定安装、检查与生产构建；CI 作为补充证据，账户/计费型 pre-runner 失败不替代本地门禁。
- `/version.json` 版本端点、客户端版本检查 hook 与 Dashboard 更新提示。
- 发布、试点、工作站、数据附件、DVR 对表、硬件边界和视觉计圈实验文档。

### 调整

- 产品定位统一为“FPVHelper 训练工作台 / 俱乐部训练量化”。
- 统一客户入口、内部验证入口、FPVSuperApp 共享 Supabase 与假名化统计边界。
- 生产数据库 migration 改由 FPVSuperApp 仓库拥有；当前 `FPVHELPER_ANALYTICS_SUPABASE_*` 直接写入适配器只保留为本地参考，不得配置共享项目 secret/service-role key。
- 当前本地参考 `/api/events` 与 migration 已覆盖 ingest token、工作站原子分钟配额（120 请求 / 1000 事件）和客户端退避；共享生产环境仍须改接 FPVSuperApp 受限摄入，完成前统计保持关闭。

### 未完成 / 不由本版本证明

- 未证明 main 分支保护、PR 合并、Vercel Promote、生产域、共享 Supabase migration/受限摄入或真机验收已经完成。CI 的实际状态单独记录，不作为试点唯一门禁。
