# FPVHelper 变更记录

本文件记录进入版本控制的产品变更；它不证明 CI、部署、生产或真机验收已经完成。

## [0.4.0] - 2026-09-05

### 新增

- 每位选手连接后自动读取 Betaflight Pilot Name，空名回退 Aircraft/Craft Name，旧固件使用只读 MSP_NAME；一次性名称探测不改变 100 Hz RC / 20 Hz 历史刷新。
- 保留既有手动名字，可直接改名或恢复自动；按选手隔离，断开重连重新读取，录制期间固定姓名用于画面、视频与原始数据。
- 浏览器支持时优先原生录制 MP4，不支持时在开始前明确显示 WebM；视频带打杆 OSD，JSON 单独保存原始数据，文件扩展名与真实容器匹配。
- 每个视频画面新增可见的“裁切与绑定”入口，直接定位对应选手，方便四合一输入分配画面。

## [0.3.1] - 2026-09-05

### 修复

- 视频＋打杆 OSD＋原始数据成为默认录制模式；开始按钮旁可直接切换录制内容，明确选择过“仅数据”的偏好继续保留。
- 主界面显示当前选手视频、真实遥控输入和保存目录的准备状态，提供打开输入、连接选手和授权目录的直接入口。
- 未满足全部开始条件时显示“待准备”，避免将已开启录像选项误认为已就绪；录制期间锁定模式。
- 延续当前选手画面烧录 OSD、WebM 关闭后确认收据和原始 JSON 同目录保存的流程，四人同时录制仍不在本版本范围内。

## [0.3.0] - 2026-09-05

### 新增

- 重构训练工作台、记录库与工作站设置，接回多路 UVC、选手画面裁切与独立遥控输入。
- 视频直接烧录左右摇杆及 −1000 / 0 / +1000 刻度，同时在授权目录保存原始遥控 JSON；结束时等待 WebM 写入关闭，再关联成功收据。
- IndexedDB 分块增量写入、已采集/已保存进度、历史摘要与按需读取详情。
- 采集质量与时钟/通道上下文，包括实际间隔分位数、缺口与可用时段；旧记录保持兼容。
- 本地训练备注、人工标记与 DVR 清单、合并周报、安装检查和主动本地诊断。

### 修复

- 摇杆缩小时坐标区保持正方形，各轴使用统一行程单位。
- 切换页面时采集与录像持续运行；改善收尾重试、异常输入和存储损坏的处理。视频文件关闭与记录完成前持续保留离页提醒。
- 旧库升级空间不足时保留历史记录只读访问与导出，暂停新录制；空间恢复后可重试迁移，不自动删除旧数据。
- 历史曲线在采集缺口处断开，孤立样本显示为点；详情读取失败可重试。
- 保持 100 Hz RC 采集目标与 20 Hz 历史节奏，避免重复样本和跨选手状态污染。

### 验证边界

- 录像叠层使用最新主机样本，尚未校准视频与遥控的时间偏移；主机采集缺口不等于 RF 丢包。
- 本地与模拟设备测试不替代真实桥接飞控、UVC、磁盘持续写入或业务验收。生产统计仍需满足既有明确授权和受限摄入配置，不随界面发布自动启用。

## [0.2.0] - 2026-08-31

### 新增

- CI workflow：锁定安装、检查与生产构建；CI 作为补充证据，账户/计费型 pre-runner 失败不替代本地门禁。
- `/version.json` 版本端点、客户端版本检查 hook 与 Dashboard 更新提示。
- 发布、试点、工作站、数据附件、DVR 对表、硬件边界和视觉计圈实验文档。

### 调整

- 产品定位统一为“FPVHelper 训练工作台 / 俱乐部训练量化”。
- 统一客户入口、内部验证入口、FPVSuperApp 共享 Supabase 与假名化统计边界。
- 生产数据库 migration 改由 FPVSuperApp 仓库拥有；当前 `FPVHELPER_ANALYTICS_SUPABASE_*` 直接写入适配器只保留为本地参考，不得配置共享项目 secret/service-role key。
- 当前本地参考 `/api/events` 与 migration 已覆盖 ingest token、工作站原子分钟配额（120 请求 / 1000 事件）和客户端退避；共享生产环境仍须改接 FPVSuperApp 受限摄入，完成前统计保持关闭。

### 未完成 / 不由本版本证明

- 未证明 main 分支保护、PR 合并、Vercel Promote、生产域、共享 Supabase migration/受限摄入或真机验收已经完成。CI 的实际状态单独记录，不作为试点唯一门禁。
