# 每位选手预绑定地面 RX 换人 SOP

## 固定原则

- 每位选手拥有独立 `Bridge FC + Ground ELRS RX` 套件，提前在拆桨台架与该选手遥控器完成绑定和通道核对。
- 现场不共享一只 RX 临时重绑，不复制或记录 Binding phrase。
- Bridge FC 不接 ESC/电机，只通过 USB 接入工作站并接受只读 MSP 请求。
- 同一时刻只让当前选手遥控器、机上系统和对应地面桥上电；任何链路疑问先停飞。

## 换人步骤

1. 结束当前 Session，确认本地保存和导出完成，台账记录 `recording_id`。
2. 当前飞行器落地、断电并按现场规则拆桨；关闭当前遥控器。
3. 从 USB 拔下当前选手整套地面桥，收回标有代号/套件号的防护盒。
4. 取出下一位选手的整套地面桥；核对选手代号、FC+RX 套件号和台账映射。
5. 只给下一位遥控器与对应桥上电，在拆桨状态验证 CH1–CH4、Arm/AUX 和 failsafe 行为。
6. 连接 FPVHelper；只有首帧真实 `MSP_RC` 后显示 live、通道方向正确且选手代号一致，才允许开始新 Session。
7. 任何异常都停止流程，记录套件号/错误码；不要切演示模式继续计入训练。
