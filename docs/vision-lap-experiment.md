# 视觉计圈独立实验 runbook

## 边界

视觉 YOLO 计圈是许可后的独立实验，不是人工 Marker 的升级版，也不属于当前试点承诺。人工 Marker 只用于 DVR 复盘定位。视觉实验即使达到门槛，也仍是训练辅助数据，不构成赛事认证、排名、裁决或替代正式计时器的声明。

## 升级宣传的固定门槛

在查看独立测试结果前冻结模型、置信度阈值和去重窗口，并同时满足：

- 独立测试集至少 `300` 次人工真值或正式计时器对照穿越。
- 召回率 `>=98%`：正确识别穿越 / 真值穿越。
- 误报 + 重复计数合计 `<=1%`：以真值穿越数为分母。
- 穿越时间偏差 `P95 <=100 ms`。
- 所有低置信度事件可被人工复核；不同灯光、场地和视频输入分层报告。

未全部达到时只能写“实验中”及真实结果，不能写“已达标”或用训练集成绩代替。

## 数据集计划

1. 先定义场景矩阵：室内/室外、顺光/逆光/暗光、模拟/DJI/Walksnail/HDZero、不同分辨率/帧率、单机/多机、遮挡和抖动。
2. 每个 Session 整段划入 train、validation 或 test，禁止同一录像切片跨集合，避免相邻帧泄漏。
3. test 集在阈值冻结前保持不可见；至少 300 次真值全部来自 test。
4. 视频素材必须有书面授权、明确保留/删除日期和访问人；不得把当前试点 DVR 默认收走。
5. 保存数据集版本、文件哈希、授权引用、场景标签和排除原因；不保存真实姓名。

## 标注规范

- 真值事件定义：飞行器参考点首次穿越冻结的门平面；记录时间戳和可见性。
- 每个事件标注 `session_id`、`frame/time`、门编号、方向、遮挡、光照、视频系统和标注人。
- 两名标注人独立标注至少 20%；分歧由第三人裁决并保留原因。
- 模糊、画面中断、门外擦过和反向穿越分别定义，不在看结果后改口径。
- 正式计时器仅作为已核验时间源时使用；型号、固件、导出方式和时钟对齐写入实验记录。

## 实验步骤

1. 冻结数据集版本与 split 清单。
2. 只在 train 训练；validation 用于模型选择和阈值候选。
3. 在查看 test 前冻结模型权重、置信度阈值、NMS/追踪和重复去除窗口。
4. 对 test 一次性推理，保存逐事件预测、延迟、硬件环境和日志。
5. 由不知道模型预测的复核人检查 false negative、false positive、duplicate 和时间误差。
6. 按总体与每个场景分层计算指标；任一关键场景样本不足时标记“证据不足”。
7. 产出可复现实验记录；不要上传未获授权的视频或把模型结果写入试点生产台账。
