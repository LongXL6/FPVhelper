# DVR 与人工 Marker 对表流程

人工 Marker 的作用是让教练在 DVR 中快速定位复盘时刻，不是圈数、圈速、视觉识别或赛事计时。

## 开始前

1. 校对工作站墙上时钟和 DVR 设备显示时间；记录二者差值，不要求假装帧级同步。
2. 开始 DVR 录像后，让画面拍到工作站时钟至少 2 秒，或记录 DVR 文件开始的墙上时间。
3. 开始 FPVHelper Session，并在台账记录 `wallClockStartedAt`、DVR 文件代号和已知时差。

## 训练中

- 发生需要复盘的片段时打人工 Marker，使用“炸机 / 撞门 / 漂亮 / 油门过猛 / 手动”标签。
- Marker 只保存相对 Session 时间与墙上时刻；不写“第几圈”或“圈速”。

## 复盘

1. 根据 Marker 墙上时刻减去 DVR 文件开始时刻，跳到近似位置。
2. 前后至少查看 5 秒，确认实际事件；记录偏差和复盘结论。
3. 若偏差持续变化，说明设备时钟漂移或录像分段，重新拍时钟并记录新偏移。
4. 只报告实际节省的复盘分钟；没有基线时不宣称效率提升。
